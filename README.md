# راه عدالت — نسخه 3.3

نسخه Android بازی آموزشی «راه عدالت» با تمرکز روی پرونده ۱ (امیر).

## مسیر پرونده ۱

دفتر → کتابخانه → پرونده ۱ → اتاق امیر → گفت‌وگو → کیف → تصویر واقعی محتویات باز کیف → سه مدرک:

1. گوشی: ورود رمز بدون نمایش خودِ جواب.
2. رسید: پازل ۲۲ تکه با کادر مونتاژ، کادر تکه‌های نامرتب، چهار جهت و چرخش.
3. DVD: بررسی فریم کلیدی فیلم.

پس از حل هر سه مدرک، بازی به‌صورت اجباری وارد آموزش «دادخواست» و سپس تست همان آموزش می‌شود.

## RTL

تمام متن‌های فارسی از helper مشترک `text()` عبور می‌کنند و با `StaticLayout` و `TextDirectionHeuristics.RTL` راست‌به‌چپ رسم می‌شوند.

## Build

Build توسط GitHub Actions در `.github/workflows/build-apk.yml` انجام می‌شود.


## نسخه 3.4 — اصلاح چهارگانه
- متن‌های داخل باکس‌های تعاملی با RTL و مرکز عمودی/افقی یک‌دست شدند.
- گوشی پس از رمز ۱۳۹۰ یک صفحه اصلی تعاملی دارد؛ پیام‌ها و رسید واریز قابل باز شدن هستند. رمز فقط در دیالوگ امیر به‌صورت سرنخ تولد ۱۳۹۰ آمده و روی صفحه معما نمایش داده نمی‌شود.
- پازل رسید با ۲۲ قطعه از یک رسید کامل بازسازی شده و قطعات در سینی به‌صورت نامرتب شروع می‌شوند؛ چرخش از جهت‌ها جداست.
- ناحیه امن بالا و پایین برای کنترل‌های بازی در نظر گرفته شد تا با نوارهای سیستمی گوشی تداخل نداشته باشند.
